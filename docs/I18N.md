# Internationalization (i18n) — M22

NØVA Flash Studio is fully offline and ships five UI languages:

| Code | Language | Fallback |
|---|---|---|
| `de-DE` | Deutsch | — |
| `en-GB` | English (UK) | **fallback for all missing keys** |
| `da-DK` | Dansk | → en-GB |
| `fr-FR` | Français | → en-GB |
| `pl-PL` | Polski | → en-GB |

## Architecture

- `crates/nova-app/i18n/<locale>.json` — flat `section.key` → string
  maps. UTF-8 **without BOM**, embedded at compile time via
  `include_str!` (no runtime file access, fully offline).
- `crates/nova-app/src/i18n.rs` — `Lang` enum, `t(key)`,
  `tf(key, args)` (`{name}` placeholders), lookup chain
  `active → en-GB → key`, missing-key tracking.
- Persistence: `<edition-config-dir>/app-settings.json`
  (`{"language": "de-DE"}`). Edition config dirs are isolated
  (`NOVA Flash Studio{, Edu, Enterprise}`), so the language choice is
  per-edition and never shared.
- First run: `language_wizard.rs` shows a branded picker before the
  splash screen when no language is stored. Re-openable from
  **Hilfe → Sprachassistent** and from the settings dialog
  (**Allgemein → Sprache** combo applies instantly).

## Adding a string

1. Add the key to **all five** `i18n/*.json` files (tests enforce
   identical key sets and placeholder counts).
2. Use `i18n::t("section.key")` or `i18n::tf("section.key", &[("name", value)])`.
3. Keep keys stable — renaming a key is a breaking change for
   translations.

## Tests

`cargo test -p nova-app i18n` verifies: identical key sets across all
locales, valid UTF-8 without BOM, consistent `{placeholder}` counts,
fallback chain, placeholder substitution, locale-code parsing and
per-edition persistence including corrupt-config fallback.

## Coverage status (honest)

Translated: menu bar, toolbar, mode rail, bottom dock tabs, status
bar, About/Help/New-Project/Unsaved dialogs, settings language
section, first-run wizard, Edu/Enterprise **tab labels**.

Not yet migrated: deep feature-panel literals inside
`properties.rs`, `stage_view.rs`, `timeline_view.rs`, `tree.rs`,
`code_view.rs`, `ai_editor.rs`, `classroom_view.rs`,
`enterprise_view.rs` tab *content*, and German error strings produced
by domain crates (`nova-ent`, `nova-edu`). These remain German source
literals and are the next translation pass; the infrastructure supports
adding them without architectural changes.
